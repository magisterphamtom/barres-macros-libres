# Barres de Macros Libres

Module pour **Foundry VTT v13 et v14** qui remplace la barre de macros (hotbar) par une version plus souple.

## Fonctionnalités

- **Déplaçable n'importe où** à l'écran avec la poignée, position mémorisée et verrouillable.
- **De 1 à 5 barres** affichées en même temps (chaque barre correspond à une page de la hotbar).
- **Disposition horizontale ou verticale.**
- **Taille des cases réglable** (20 à 72 px).
- **Raccourcis au pavé numérique** : barre 1 = 1 à 0, barre 2 = Ctrl + 1 à 0, barre 3 = Alt + 1 à 0. Toutes les touches sont modifiables dans *Configurer les contrôles*.
- Glisser-déposer depuis le répertoire des macros, les compendiums ou les fiches (objets, sorts selon le système).
- Clic droit sur une case : exécuter, modifier, retirer ou créer une macro.
- **Alt + M** (QWERTY et AZERTY) ou le bouton de réduction pour replier les barres en une petite pastille, cliquable pour les rouvrir.

Les emplacements sont ceux de la hotbar native de Foundry : aucune macro n'est perdue si le module est désactivé.

## Installation

Dans Foundry, **Modules → Installer un module**, puis colle ce lien dans le champ *URL du manifeste* :

```
https://github.com/magisterphamtom/barres-macros-libres/releases/latest/download/module.json
```

## Réglages

*Paramètres → Configurer les paramètres → Barres de Macros Libres* : affichage, nombre de barres, disposition, taille des cases, masquage de la hotbar native.
